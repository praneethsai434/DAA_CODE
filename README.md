## 🛠️ How to Compile and Run

You can compile and run any of the C programs using GCC or Clang:

```bash
# Example: Compiling lab_code_10.c (Merge Sort)
gcc lab_code_10.c -o lab_code_10.exe

# Running the executable on Windows
.\lab_code_10.exe
```

## 🚀 How to Add and Push New Code via VS Code

1. Open this repository folder in **VS Code**:
   `File` -> `Open Folder...` -> Select `c:\Users\HP\OneDrive - UPES\SEM-3\DAA\LAB CODE`.
2. Create your new file (e.g., `lab_code_11.c`) and write your code.
3. Open the **Source Control** panel in VS Code (`Ctrl + Shift + G`).
4. Click the **`+`** (Stage Changes) next to your new file.
5. Type a commit message (e.g. `Add lab_code_11: Quick Sort`) and click **Commit** (or `Ctrl + Enter`).
6. Click **Sync Changes** (or **Push**) to upload it to GitHub!
